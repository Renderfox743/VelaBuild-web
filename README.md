# VelaBuild Web Platform

A web-based development platform for creating Mi Band 9 applications. This is the web interface for the VelaBuild CLI tool.

## Features

- **Landing Page**: Introduction to VelaBuild with feature highlights
- **Authentication**: Login and signup functionality
- **Dashboard**: Overview of your projects and builds
- **Code Editor**: Edit UX files with syntax highlighting
- **Project Download**: Download your built projects and source code
